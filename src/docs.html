SISMO PANAMÁ · API

Datos sísmicos abiertos para Panamá: el listado del Instituto de Geociencias (IGC-UP) convertido a JSON/GeoJSON, fusionado con USGS y EMSC, con detección de réplicas. Sin clave, con CORS abierto.
← Volver a la app · By @elprotectorado

Endpoints

GET/api/quakes — todos los sismos fusionados (IGC + USGS + EMSC), con role (main / after / fore / single), nrep y magnitudes por fuente. GET/api/quakes.geojson — igual, en GeoJSON. GET/api/igc · /api/igc.geojson — conversión del listado oficial de sismosgeociencias.up.ac.pa (últimos 7 días, con estado PRELIMINAR / REVISADO). GET/api/latest — último sismo en Panamá y el más fuerte de 24 h. GET/api/sequences — secuencias sísmicas: réplicas y probabilidad estimada de réplicas (Reasenberg & Jones, parámetros genéricos). GET/api/stats — conteos por día, por magnitud, valor b de Gutenberg-Richter, energía liberada. GET/api/status — salud de cada fuente (latencia, errores, datos obsoletos) y estado del push.

Parámetros de filtro (quakes / igc)

ParámetroDescripción
min, maxMagnitud mínima / máxima
daysSolo los últimos N días (máx. 8)
sinceMarca de tiempo (ms) o fecha ISO
region=panSolo dentro del recuadro de Panamá (4.5–10.5°N, 84–76.5°O)
src=IGC|USGS|EMSCEventos confirmados por esa fuente
st=RSolo revisados (IGC) / revisados (USGS)
role=after|main|fore|singleFiltra por rol en la secuencia
limit, fresh=1Límite de filas · ignora la caché de 15 s

Ejemplos

curl "/api/igc?min=3&days=2"
curl "/api/quakes.geojson?region=pan&min=4"
curl "/api/sequences"
fetch('/api/latest').then(r => r.json()).then(console.log)

Notas de calidad

  • El listado del IGC se lee y se normaliza en cada consulta (caché 15 s). Las horas locales (UTC−5) se convierten a UTC. Si el sitio del IGC no responde, la API usa el último dato bueno (hasta 30 min) y lo marca stale en /api/status.
  • Cuando varias redes reportan el mismo sismo (±100 s y <120 km) se fusionan; la magnitud principal es la del IGC si existe, luego USGS, luego EMSC. El resto queda en mags.
  • Información de apoyo, no oficial. Para decisiones de seguridad consulta al IGC-UP y SINAPROC. Emergencias: 911.

Activar alertas con la app cerrada (Web Push)

  1. Workers → tu Worker → Settings → Bindings → Add → KV namespace. Variable: SISMO_KV (crea un namespace nuevo).
  2. Settings → Triggers → Cron Triggers → Add: * * * * * (cada minuto).
  3. Opcional: variable VAPID_SUBJECT (por ejemplo mailto:tu@correo.com) y PUSH_BUDGET (envíos por minuto; 40 en plan gratuito).
  4. Abre la app → Ajustes → Alertas push → Activar. Las claves VAPID se generan solas la primera vez.
